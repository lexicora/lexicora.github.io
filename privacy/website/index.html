Website privacy policy

Last updated 16 October 2026.

This policy covers this website, lexicora.github.io. The Lexicora extension has a policy of its own: it keeps everything on your device and sends nothing anywhere. A website cannot quite say the same, because it has to be served from somewhere. This page says what that means.

Who is responsible

This website is run by Timothy (@tgmaurer), who develops Lexicora. Write to hello@tgmaurer.dev about anything on this page.

What this website does not do

  • It sets no cookies.
  • It has no analytics, no tracking pixels, no advertising and no fingerprinting.
  • It has no accounts, forms or comments, so it never asks you for anything.
  • It loads nothing from other sites. Fonts, images and icons are served from this website itself, so no font service or content network sees your visit.

Hosting: GitHub Pages

The website is hosted on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, USA. Like any web server, GitHub's server receives what your browser sends with every request: your IP address, the address of the page, the time, and your browser's name and language.

GitHub states that when a GitHub Pages site is visited, “the visitor's IP address is logged and stored for security purposes”, whether or not you are signed in to GitHub. Lexicora has no access to those logs and receives no visitor statistics from them.

GitHub handles this data under the GitHub General Privacy Statement, which also says how it is protected and kept. GitHub may process it in the United States. For transfers from the EU, the UK and Switzerland, it relies on the EU–U.S. Data Privacy Framework and on the European Commission's standard contractual clauses.

Serving the website reliably and keeping it secure is the legitimate interest these requests rest on (Article 6(1)(f) GDPR for visitors in the EU).

The small script

A few lines of JavaScript make the site smoother: the logo scrolls back to the top, and the screenshot viewer's Back button returns you to the homepage in one step, exactly where you were. To do that, the script keeps a note in your browser's session storage of how many screenshots you have paged through. The note stays in your browser, is never sent anywhere, and is deleted when you close the tab. Everything on the site works with JavaScript switched off.

In Chrome and Edge, the site also asks the browser to load the next and previous screenshot pages in advance, and a screenshot's page when you rest the pointer on it, so they open at once. Those pages come from this website, like any other page of it.

Links to other sites

The Chrome Web Store, Firefox Add-ons, Microsoft Edge Add-ons and GitHub are linked from this website. Following a link opens that site under its own privacy policy. Nothing is sent to them before you click.

The links to the Chrome Web Store and Firefox Add-ons carry a tag in their address (utm_source=lexicora-website&utm_medium=hero, for instance) that says the visit came from this website and which button was used, so each store's statistics can count those visits. The tag is the same for everyone and says nothing about you.

If you write

An email to hello@tgmaurer.dev is used to answer you, and kept only as long as that takes. It is never added to a list or passed on.

Your rights

The Swiss Federal Act on Data Protection (FADP) and, for visitors in the EU, the GDPR let you ask which data about you is processed, and have it corrected or deleted. You can also object to its processing, and complain to a data protection authority: in Switzerland the Federal Data Protection and Information Commissioner (FDPIC), in the EU the authority where you live.

This website itself holds no data about its visitors. For the server logs, GitHub is the one to ask, through its privacy statement or its data protection officer at dpo[at]github[dot]com. For an email you sent, write to hello@tgmaurer.dev.

Changes

If this website ever adds something that changes what is said here, such as analytics or a different host, this page says so first, with a new date at the top.
